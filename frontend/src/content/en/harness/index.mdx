# DeerFlow Harness

The harness is the runtime layer that powers DeerFlow. In this repository it
currently lives in `backend/packages/harness/deerflow/`.

## Current Packaging Reality

The harness is not yet distributed as a public PyPI package in this fork’s
workflow. Today the practical way to use it is:

- work from the repository source tree
- import the runtime modules directly
- use `DeerFlowClient` when you want an embedded Python entry point

## What The Harness Provides

- lead-agent creation
- middleware composition
- model resolution
- sandboxed file and command execution
- skills and MCP tool loading
- memory
- subagent orchestration
- an embedded Python client

## Who This Section Is For

Use this section if you want to:

- build your own app on top of DeerFlow runtime primitives
- understand how the lead agent is assembled
- embed the runtime into Python without the full HTTP stack
- customize tools, skills, agents, or middleware
